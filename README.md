# Project Description 
	This project features a terminal based number guessing game on python. It begins by explaining the game, and then offers three different difficulty levels that determine how many attempts the user has to guess the randomly generated number. If easy is selected, the user has 10 attempts, medium allows 7 attempts, and hard allows 5 attempts. The game lets the user know if the guess they input is too high or too low in comparison to the random number. At the end of the game, if they win their attempts are displayed, if not the correct answer is displayed. Both outcomes have a prompt that allows the user to replay the game if they wish.  


# Instructions
1. First load the game into the terminal by using the cd command and then open a python terminal for the file. 
2. Then the game will load and allow the user to pick a difficulty, make sure that the spelling and capitalizations are correct. If not, it defaults to medium difficulty. 
3. The game now begins, the user has limited attempts(based on their selected difficulty) to find the randomly selected number. 
    - Make sure to only input integers as guesses. 
4. At the end of the game, there is an option to play agiain and the user can select if they wish to continue or not by typing "yes" or "no".
